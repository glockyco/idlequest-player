# Community knowledge from the Project 1999 wiki

Every row is a candidate fact from the Project 1999 wiki, to verify against the game before the account relies on it, and its status is `confirmed` (this repository already shows IdleQuest does it), `different` (this repository shows IdleQuest differs) or `unchecked` (no evidence either way). Pages were read through the public mirror p99.funcamp.net because wiki.project1999.com blocks automated reads, and every link points to the official page of the same name.

## Leveling zones

The Per-Level Hunting Guide lists spots by the level range where mobs con blue, for solo players and for groups. The tables keep only the group ranges, one row per zone and band, and mark each zone against the rotation rows in `data/band-rotations.json` and the live zone list in `data/live-zones.json`.
