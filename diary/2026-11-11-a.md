# 2026-11-11 (after midnight): the epic model reads the scripts the server runs

## What happened

- Step 1 of the epic model went in (`docs/plans/epic-model.md`). The analyzer reads every enabled quest script into events, conditions and actions, and the model picks the cheapest way to each piece of every class epic. `bun tools/epic-model.mjs` prints the steps, the gaps and the blockers.
- Demand for the epics now comes from each epic's chosen steps instead of every path the old quest graph could walk. `tools/lib/quest-graph.mjs` and its check are gone. Their recipes and summoning spells moved into the model.
- Every reader of the spawn tables now goes through one reader, `liveSpawnRows`, with the rules below. Three tools had private copies of the content reader.
- The model's first runs had many false blockers and false shortcuts. Each one traced back to a fact about the content:
  - Spawn rows need the live expansion. The server plays Classic through Velious, and Anson McBale's Highpass row needs expansion 12.
  - An entry at weight 0 never spawns (`epics.md`, rule 11). The gear plan had counted a group whose only entry has weight 0 as spawning every time. #Tantor became a most-wanted target that way.
  - Everfrost's 265 spawn rows name the zone "Everfrost". The case-sensitive match hid every Everfrost spawn, including the Lich of Miragul that the Paladin epic needs.
  - Script file names write a backtick as a hyphen: `Oracle_of_K-Arnon.lua` belongs to Oracle_of_K\`Arnon.
  - The export keeps the database's 569 disabled scripts, among them every script under `v0` and `v1`. Its index marks them, and the model skips them.
  - The content keeps copies of many scripts under a zone's other names, such as `freeportwest` beside `freportn`. A copy whose zone has no such NPC belongs to none, so the choice between copies no longer depends on the directory order.
  - The server crafts without a container, so a recipe's container is no input.
  - 19,647 of the 22,802 recipes are disabled, and 3,706 need a later expansion. A craftable recipe is enabled, shown in the Advanced recipe window and inside the live expansion, as the tradeskill tool already read them, and the model now reads them the same way. None of the 16 recipes in the epics' steps changed.
  - The Tradeskill Bank's catalog sells recipe ingredients into the bank. It prices a combine's inputs, but nothing has shown that a bought ingredient can be taken out for a hand-in, so it is no general source.
- Idioms the analyzer learned:
  - `eq.handin`;
  - a spawn with a method chained on it or kept in a local;
  - the zone's hour;
  - `GetNPCTypeID`;
  - any `Get...Faction` lookup;
  - script variables, such as the Undead Bard's `spawn_trakanon`, which a trade sets and his death tests;
  - an event's own variables, such as Tykar Renlin's `morechampagne`, which only the four-champagne trade sets.
- A condition the analyzer cannot read now closes its branch. Before, it passed for free: the Cleric chain skipped the whole Coral Statue chain through an unread `eq.handin` at the seeker in the Temple of Solusek Ro.
